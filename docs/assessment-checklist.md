# Assessment checklist
- [ ] Run `mvn clean test` on Java 21 / Maven 3.9+.
- [ ] Start Kafka with `docker compose up -d`.
- [ ] Start Kafka and the single Spring Boot application; test the end-to-end event flow.
- [ ] Add a real Git repository and meaningful commits; do not fabricate history.
- [ ] Complete AI journal with actual prompts and review decisions.
- [ ] Be ready to explain service boundaries, REST vs Kafka, eventual consistency, lifecycle rules, liability assumptions, and production reliability gaps.
- [ ] Be transparent that authentication, outbox, DLQ, durable databases, and audit history are not included.
